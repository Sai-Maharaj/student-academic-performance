# Data dictionary

See README.md for complete column definitions, ranges and analytical rules.

The source is synthetic, generated by tools/generate_dataset.py with NumPy seed 20260930. One row = Student_ID + Semester + Subject. No actual college records were used.

Derived columns: Total_Mark (0–100), Result (Pass/Fail), Grade (A+ to F), Support_Reason (text), Support_Needed (boolean). These are outputs and must not be added to the upload template.
